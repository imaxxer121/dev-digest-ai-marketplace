# Cost experiment — evidence pending

This document is a protocol until real trial records are attached. No measurements
or successful outcomes have been invented.

The fixed scenario prepares a spec and plan for an independent release-notes CLI:
add a positive integer `--limit` option, maximum 100; reject invalid or duplicate
values with exit code 2; preserve default behavior, stable ordering, empty output
and offline operation. The same scenario, model, routing, target revision and
quality evaluator apply to every trial.

Baseline loads repeated shared practice bodies alongside the SDD role prompts.
The single treatment replaces those repeated bodies with demand-loaded namespaced
references. No task requirement or quality gate may change between groups.
Use at least three fresh trials per group and preserve order plus raw traces.
Record failures as failures; divide total usage including failed attempts by the
number of successful workflows. Zero successes yields an unavailable ratio.

Quality requires concrete handling of option boundaries and compatibility,
source-backed target commands, a dependency/ownership-aware plan, verification
coverage and no product edits during spec/plan authoring. Model graders, if used,
must be identified as such and cannot replace deterministic evidence checks.

Record actual input/output/cache tokens and elapsed milliseconds from native
CLI events. Billed USD is unavailable from a subscribed Codex CLI session;
report it as null, not free or zero. Report uncached input and total tokens per
successful workflow as explicitly labeled cost proxies, plus median latency and
quality success rate. Estimates using a price schedule belong in a separate
column with the schedule/date and must not be called provider billing.
