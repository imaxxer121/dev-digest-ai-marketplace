# engineering-paved-path

Focused architecture, TypeScript, UI, service and data practices for SDD work.

Install from `dev-digest-ai-marketplace`. The component directory is the source
of truth; the catalog lists each actual skill and agent. Local project guidance
supplies architecture, paths and test commands. This package has no setup hooks,
MCP servers, credentials or network integrations.

Dependencies: none.

```sh
claude plugin install engineering-paved-path@dev-digest-ai-marketplace
```
