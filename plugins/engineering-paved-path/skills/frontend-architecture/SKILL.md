description: "Fit a UI change into the target repository page, component, query and translation layers."
---

Discover the target route/component layout rather than assuming a framework.
Keep route orchestration, reusable controls and query hooks in the established
layers. Use the existing design tokens and localization system. Make browser
state reproducible with a URL or stored selection when the flow requires it.
Use engineering-paved-path:react-best-practices and
engineering-paved-path:react-testing-library only for React work.
