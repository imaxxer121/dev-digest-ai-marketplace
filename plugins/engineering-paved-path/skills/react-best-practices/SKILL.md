---
name: react-best-practices
description: "Design React state and async rendering when the target feature changes a React UI."
---

Use the target application's existing component, styling and data-query patterns.
Derive state when possible; reserve effects for synchronization. Represent
loading, unavailable, empty and error states independently. Keep server data
in the existing query layer and use stable identity for list items. Preserve
accessible labels, keyboard activation and focus when replacing controls.
