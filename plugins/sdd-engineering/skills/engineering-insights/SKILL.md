description: "Record verified reusable discoveries in the target repository's existing engineering notes after validation."
---

Discover the target's note convention, or use the affected module's INSIGHTS.md
when none exists. Read existing entries first. Record only a useful verified
discovery with date, practical consequence, final path:line and actual command
result. Distinguish a hypothesis from an observation and fixtures from model
quality. Do not copy secrets, personal paths, routine change lists or assumptions
about another application's modules. This skill does not authorize publication.
